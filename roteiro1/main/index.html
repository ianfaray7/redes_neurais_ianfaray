    Relatório - Redes Neurais: Separabilidade de Classes e Pré-processamento

    Este repositório contém a implementação de três exercícios sobre fundamentos de redes neurais, explorando separabilidade de classes e técnicas de pré-processamento de dados.

    Exercício 1: Exploração da Separabilidade de Classes em 2D

    Objetivo

    Gerar um dataset sintético 2D com 4 classes gaussianas e analisar a separabilidade das classes.

    Implementação

    • Geração de 400 amostras (100 por classe) com distribuições gaussianas específicas
    • Visualização em scatter plot com cores distintas por classe
    • Análise das fronteiras de decisão necessárias

    Código Completo

    import numpy as np
import matplotlib.pyplot as plt

# ===== 1) Parâmetros e geração dos dados =====
rng = np.random.default_rng(42)

params = {
    0: {"mean": np.array([2.0, 3.0]),  "std": np.array([0.8, 2.5])},
    1: {"mean": np.array([5.0, 6.0]),  "std": np.array([1.2, 1.9])},
    2: {"mean": np.array([8.0, 1.0]),  "std": np.array([0.9, 0.9])},
    3: {"mean": np.array([15.0, 4.0]), "std": np.array([0.5, 2.0])},
}

def gen_class(mean, std, n=100, rng=None):
    """Gera n amostras 2D de uma Gaussiana com covariância diagonal (std^2)."""
    if rng is None:
        rng = np.random.default_rng()
    cov = np.diag(std**2)
    return rng.multivariate_normal(mean, cov, size=n)

# 100 pontos por classe (total = 400)
data = {c: gen_class(p["mean"], p["std"], n=100, rng=rng) for c, p in params.items()}

# ===== 2) Gráfico de dispersão (todas as classes) =====
plt.figure(figsize=(7,6))
for c in sorted(data.keys()):
    X = data[c]
    plt.scatter(X[:,0], X[:,1], s=18, alpha=0.75, label=f"Class {c}")
plt.title("Synthetic 2D Dataset (4 Gaussian Classes)")
plt.xlabel("x1")
plt.ylabel("x2")
plt.legend()
plt.grid(True, linestyle="--", alpha=0.4)
plt.tight_layout()
plt.savefig("graficos_ex1/scatter_ex1.png", dpi=150)
plt.show()

# ===== 3) Segundo gráfico com "fronteiras" esboçadas =====
plt.figure(figsize=(7,6))
for c in sorted(data.keys()):
    X = data[c]
    plt.scatter(X[:,0], X[:,1], s=18, alpha=0.75, label=f"Class {c}")

# (a) Linha vertical para isolar Classe 3 (à direita)
plt.axvline(11, linestyle="--", linewidth=2, label="Boundary: isolate Class 3")

# (b) Linha diagonal para separar Classe 2 das Classes 0/1
xline = np.linspace(3, 11, 200)
yline = 0.5 * xline + 0.25
plt.plot(xline, yline, linestyle="--", linewidth=2, color='green', label="Boundary: split Class 2")

# (c) Linha vertical para separar Classe 1 da Classe 0
xline3 = np.full(200, 3.5)  # x constante = linha vertical
yline3 = np.linspace(-3, 12, 200)  # y varia
plt.plot(xline3, yline3, linestyle="--", linewidth=2, color="purple", label="Boundary: split Class 1/0")

plt.title("Dataset with Sketched Candidate Decision Boundaries")
plt.xlabel("x1")
plt.ylabel("x2")
plt.legend()
plt.grid(True, linestyle="--", alpha=0.4)
plt.tight_layout()
plt.savefig("graficos_ex1/boundaries_ex1.png", dpi=150)
plt.show()

    Resultados

    Análise

    Observações sobre Separabilidade: - Classes 0 e 1 se sobrepõem na região central do gráfico, tornando difícil separar com uma linha reta - Classe 3 está bem isolada no lado direito, sendo fácil de identificar - Classe 2 forma um grupo compacto na parte inferior

    Fronteiras de Decisão Necessárias: Para separar todas as classes, precisamos de múltiplas linhas: 1. Uma linha vertical para isolar a Classe 3 2. Uma linha diagonal para separar a Classe 2 3. Uma linha adicional para distinguir Classes 0 e 1

    Por que uma Rede Neural? Um perceptron simples só consegue fazer separações lineares (uma linha reta). Como nossos dados precisam de várias linhas para separação, uma rede neural com camadas ocultas é necessária para aprender essas fronteiras mais complexas.

    Exercício 2: Não-linearidade em Dimensões Superiores

    Objetivo

    Criar um dataset 5D não-linearmente separável e visualizar usando redução de dimensionalidade.

    Implementação

    • Geração de 1000 amostras (500 por classe A e B) usando distribuições multivariadas
    • Aplicação de PCA para reduzir de 5D para 2D
    • Visualização da projeção 2D

    Código Completo

    # Exercise 2 — Non-Linearity in Higher Dimensions
# Requisitos básicos: numpy, matplotlib
# (Opcional) classificar: scikit-learn

import numpy as np
import matplotlib.pyplot as plt

# ---------- 1) Parâmetros e geração dos dados (5D) ----------
rng = np.random.default_rng(7)

mu_A = np.zeros(5)
Sigma_A = np.array([
    [1.0, 0.8, 0.1, 0.0, 0.0],
    [0.8, 1.0, 0.3, 0.0, 0.0],
    [0.1, 0.3, 1.0, 0.5, 0.0],
    [0.0, 0.0, 0.5, 1.0, 0.2],
    [0.0, 0.0, 0.0, 0.2, 1.0],
])

mu_B = np.full(5, 1.5)
Sigma_B = np.array([
    [1.5, -0.7, 0.2, 0.0, 0.0],
    [-0.7, 1.5, 0.4, 0.0, 0.0],
    [0.2, 0.4, 1.5, 0.6, 0.0],
    [0.0, 0.0, 0.6, 1.5, 0.3],
    [0.0, 0.0, 0.0, 0.3, 1.5],
])

n_per_class = 500
A = rng.multivariate_normal(mu_A, Sigma_A, size=n_per_class)
B = rng.multivariate_normal(mu_B, Sigma_B, size=n_per_class)

X = np.vstack([A, B])                 # (1000, 5)
y = np.array([0]*n_per_class + [1]*n_per_class)  # 0=A, 1=B

# ---------- 2) PCA (NumPy): 5D -> 2D ----------
Xc = X - X.mean(axis=0, keepdims=True)
Cov = np.cov(Xc, rowvar=False)        # (5x5)
eigvals, eigvecs = np.linalg.eigh(Cov)
order = np.argsort(eigvals)[::-1]     # maiores primeiro
W = eigvecs[:, order[:2]]             # autovetores dos 2 maiores autovalores
X2 = Xc @ W                           # projeção 2D

explained_ratio = eigvals[order[:2]] / eigvals.sum()
print(f"Explained variance ratio PC1, PC2: {explained_ratio[0]:.4f}, {explained_ratio[1]:.4f}")
print(f"Explained variance (total 2D): {explained_ratio.sum():.4f}")

# ---------- 3) Visualização ----------
plt.figure(figsize=(7,6))
plt.scatter(X2[y==0,0], X2[y==0,1], s=12, alpha=0.7, label="Class A")
plt.scatter(X2[y==1,0], X2[y==1,1], s=12, alpha=0.7, label="Class B")
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Exercise 2: PCA (5D → 2D) of Classes A and B")
plt.legend()
plt.grid(True, linestyle="--", alpha=0.4)
plt.tight_layout()
plt.savefig("graficos_ex2/pca_ex2.png", dpi=150)
plt.show()

    Resultados

    Análise

    O que o PCA nos mostra: - Conseguimos visualizar dados 5D em um gráfico 2D, mas perdemos algumas informações no processo - As duas classes (A e B) se misturam bastante na visualização, indicando que não são facilmente separáveis

    Por que não é linearmente separável: - Existe muita sobreposição entre as classes na projeção 2D - As classes foram geradas com padrões de correlação diferentes (matriz de covariância), criando estruturas complexas - Uma linha reta não conseguiria separar bem essas classes

    Necessidade de Redes Neurais: Este é exatamente o tipo de problema onde redes neurais brilham: - Elas podem aprender padrões complexos que métodos lineares não conseguem - Múltiplas camadas permitem descobrir relações escondidas nos dados - Funções de ativação não-lineares ajudam a modelar essas relações complexas

    Exercício 3: Pré-processamento de Dados Reais

    Objetivo

    Preparar o dataset Spaceship Titanic para uso em redes neurais com função de ativação tanh.

    Dataset

    • Objetivo: Prever se um passageiro foi transportado (Transported)
    • Features numéricas: Age, RoomService, FoodCourt, ShoppingMall, Spa, VRDeck
    • Features categóricas: HomePlanet, CryoSleep, Destination, VIP, Deck, Side

    Código Completo

    # Exercício 3 — Spaceship Titanic (CSV local) • Pipeline completo p/ NN com tanh
# Requisitos: pandas, numpy, scikit-learn, matplotlib, scipy

import os
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, MinMaxScaler
from sklearn.impute import SimpleImputer
from scipy import sparse

# =========================
# 1) Ler CSVs locais
# =========================
TRAIN_CSV = "train.csv"   # ajuste o caminho se necessário
assert os.path.exists(TRAIN_CSV), f"Arquivo não encontrado: {TRAIN_CSV}"
df = pd.read_csv(TRAIN_CSV)
print(f"[OK] Carregado: {TRAIN_CSV} | shape: {df.shape}")

# =========================
# 2) Descrição do dataset
# =========================
print("\nObjetivo: prever 'Transported' (1=transportado; 0=não).")
assert "Transported" in df.columns, "Coluna 'Transported' não encontrada no train.csv"

# Separar alvo e remover IDs/Name
y = df["Transported"].astype(int)
X = df.drop(columns=["Transported", "PassengerI'd", "Name"], errors="ignore")

# Engenharia mínima de 'Cabin' -> Deck / CabNum / Side
if "Cabin" in df.columns:
    cab = df["Cabin"].astype(str).fillna("nan/nan/nan").str.split("/", expand=True)
    cab.columns = ["Deck", "CabNum", "Side"]
    cab["CabNum"] = pd.to_numeric(cab["CabNum"], errors="coerce")
    X = pd.concat([X.drop(columns=["Cabin"], errors="ignore"), cab], axis=1)

# Definir listas de features
num_cols = [c for c in ["Age","RoomService","FoodCourt","ShoppingMall","Spa","VRDeck","CabNum"] if c in X.columns]
cat_cols = [c for c in ["HomePlanet","CryoSleep","Destination","VIP","Deck","Side"] if c in X.columns]

print("\nFeatures numéricas:", num_cols)
print("Features categóricas:", cat_cols)

# Relatório de faltantes (para o relatório)
missing = df.isna().sum().sort_values(ascending=False).to_frame("missing_count")
missing["missing_pct"] = (missing["missing_count"] / len(df)).round(4)
print("\nFaltantes (top 10):")
print(missing.head(10))

# =========================
# 3) Pré-processamento
# =========================
# Justificativa:
# - Numéricas: mediana (robusta a outliers) + MinMax [-1,1] (casa com tanh).
# - Categóricas: moda + OneHot (evita ordem arbitrária).
num_transformer = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", MinMaxScaler(feature_range=(-1, 1)))
])

# Compatibilidade OneHotEncoder (sklearn novo usa 'sparse_output', antigo usa 'sparse')
ohe_kwargs = {"handle_unknown": "ignore"}
if "sparse_output" in OneHotEncoder.__init__.__code__.co_varnames:
    ohe_kwargs["sparse_output"] = True
else:
    ohe_kwargs["sparse"] = True

cat_transformer = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("onehot", OneHotEncoder(**ohe_kwargs))
])

preprocessor = ColumnTransformer(
    transformers=[
        ("num", num_transformer, num_cols),
        ("cat", cat_transformer, cat_cols),
    ],
    remainder="drop",
    sparse_threshold=1.0  # mantemos esparso (muitas dummies)
)

X_prepared = preprocessor.fit_transform(X)
print("\nShape X original:", X.shape, "| Shape X preparado:", X_prepared.shape)

# =========================
# 4) Visualizações: Antes vs Depois (Age, FoodCourt)
# =========================
def _scaled_column_from_pipeline(prepared, colname):
    used_num = [c for c in num_cols if c in X.columns]
    idx = used_num.index(colname)
    col = prepared[:, idx]
    return col.toarray().ravel() if sparse.issparse(col) else np.asarray(col).ravel()

def plot_before_after(col):
    if col not in num_cols:
        print(f"[skip] {col} não está em num_cols.")
        return
    plt.figure(figsize=(12,4))
    plt.subplot(1,2,1)
    plt.hist(X[col].dropna(), bins=30, alpha=0.85)
    plt.title(f"{col} — Antes")
    plt.grid(True, ls="--", alpha=0.4)

    plt.subplot(1,2,2)
    scaled = _scaled_column_from_pipeline(X_prepared, col)
    plt.hist(scaled, bins=30, alpha=0.85)
    plt.title(f"{col} — Após MinMax [-1, 1]")
    plt.grid(True, ls="--", alpha=0.4)
    plt.tight_layout()
    plt.savefig(f"graficos_ex3/{col}_before_after.png", dpi=150)
    plt.show()

plot_before_after("Age")
plot_before_after("FoodCourt")

# =========================
# 5) Exportar dados prontos
# =========================
os.makedirs("preprocessed_out", exist_ok=True)

X_path = os.path.join("preprocessed_out", "X_minmax_n11.npz")
if sparse.issparse(X_prepared):
    sparse.save_npz(X_path, X_prepared)
else:
    np.savez_compressed(X_path, X_prepared=X_prepared)

y_path = os.path.join("preprocessed_out", "y.csv")
pd.Series(y, name="Transported").to_csv(y_path, index=False)

# Nomes de features (numéricas + dummies)
def get_feature_names(preprocessor, num_cols, cat_cols):
    num_feats = list(num_cols)
    ohe = preprocessor.named_transformers_["cat"].named_steps["onehot"]
    # método disponível em versões recentes
    if hasattr(ohe, "get_feature_names_out"):
        cat_feats = ohe.get_feature_names_out(cat_cols).tolist()
    else:
        # fallback para versões bem antigas
        cat_feats = ohe.get_feature_names(cat_cols).tolist()
    return num_feats + cat_feats

try:
    feature_names = get_feature_names(preprocessor, num_cols, cat_cols)
    with open(os.path.join("preprocessed_out", "feature_names.txt"), "w", encoding="utf-8") as f:
        f.write("\n".join(feature_names))
except Exception as e:
    print("Aviso: não foi possível salvar nomes de features:", e)

    Preparação dos Dados para Redes Neurais

    Por que preparar os dados é importante: Redes neurais são muito sensíveis à qualidade e formato dos dados de entrada. Dados mal preparados podem impedir que a rede aprenda corretamente ou tornar o treinamento muito lento.

    Valores Faltantes

    O dataset tinha cerca de 2-2.5% de valores faltantes em cada coluna, distribuídos de forma equilibrada. Isso é bom porque significa que não há um problema sistemático na coleta dos dados.

    Como tratamos cada tipo de dado:

    Features Numéricas (Age, gastos, etc.): - Valores faltantes: Substituímos pela mediana (valor do meio) - Por quê? A mediana não é afetada por valores muito altos ou baixos - Normalização: Convertemos todos os valores para o range [-1, 1] - Por quê? A função tanh que vamos usar na rede também produz valores entre -1 e 1

    Features Categóricas (planeta, destino, etc.): - Valores faltantes: Substituímos pelo valor mais comum (moda) - Por quê? Faz sentido assumir a categoria mais frequente quando não sabemos - Codificação: Transformamos em variáveis dummy (0 ou 1) - Por quê? Redes neurais só entendem números, não texto

    Por que MinMax [-1, 1] é ideal para tanh:

    A função tanh varia entre -1 e 1. Se colocarmos dados na mesma escala: - A rede não fica "confusa" com números muito grandes ou pequenos - O treinamento fica mais estável e rápido - Evitamos problemas onde a função "satura" e para de aprender

    Resultados das Transformações

    O que aconteceu com os dados:

    Feature Age (Idade): - Antes: Idades de 0 a 80 anos, distribuição normal - Depois: Mesma forma da distribuição, mas valores entre -1 e 1 - Benefício: A rede neural consegue processar melhor dados nessa escala

    Feature FoodCourt (Gastos na praça de alimentação): - Antes: Muitas pessoas gastaram 0, algumas gastaram muito (distribuição assimétrica) - Depois: Mesma distribuição, mas comprimida entre -1 e 1 - Benefício: Pessoas que gastaram muito não vão "dominar" o aprendizado da rede

    Por que essa preparação é crucial:

    Para o treinamento da rede: - Dados na mesma escala fazem a rede aprender de forma balanceada - Evita que algumas features sejam mais "importantes" só por terem valores maiores - O treinamento fica mais rápido e estável

    Para a função tanh: - Como tanh produz valores entre -1 e 1, faz sentido os dados de entrada estarem na mesma faixa - Isso mantém a rede "ativa" - ela não fica "saturada" com valores muito extremos - Os gradientes (que são usados para ajustar os pesos) ficam mais saudáveis
