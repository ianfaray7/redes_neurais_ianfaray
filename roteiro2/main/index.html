    Roteiro 2: Implementação do Perceptron para Classificação Binária

    Introdução

    Este roteiro apresenta a implementação e análise de um perceptron simples para classificação binária em dois cenários distintos: dados linearmente separáveis (Exercício 1) e dados com sobreposição parcial (Exercício 2). O objetivo é compreender como a separabilidade linear dos dados afeta a convergência e performance do algoritmo perceptron.

    Metodologia

    Implementação do Perceptron

    O perceptron foi implementado seguindo as diretrizes estabelecidas:

    • Uso de bibliotecas: Apenas NumPy para operações matriciais básicas
    • Implementação própria: Todas as operações de ativação, regra de aprendizado e forward pass
    • Regra de atualização: \(w \leftarrow w + \eta \cdot y_i \cdot x_i\) e \(b \leftarrow b + \eta \cdot y_i\)
    • Taxa de aprendizado: \(\eta = 0.01\)
    • Critério de parada: Convergência (sem atualizações) ou máximo de 100 épocas

    Função de Ativação

    O perceptron utiliza uma função de ativação de limiar (step function):

    \[f(x) = \begin{cases} 1 & \text{se } w^T x + b \geq 0 \\ -1 & \text{caso contrário} \end{cases}\]

    Internamente, os rótulos {0,1} são mapeados para {-1,+1} para facilitar a implementação da regra de aprendizado.

    Exercício 1: Dados Linearmente Separáveis

    Geração dos Dados

    Parâmetros utilizados: - Classe 0: \(\mu_0 = [1.5, 1.5]\), \(\Sigma_0 = \begin{bmatrix} 0.5 & 0 \\ 0 & 0.5 \end{bmatrix}\) - Classe 1: \(\mu_1 = [5.0, 5.0]\), \(\Sigma_1 = \begin{bmatrix} 0.5 & 0 \\ 0 & 0.5 \end{bmatrix}\) - Amostras: 1000 por classe

    Código do Exercício 1

    import numpy as np
import matplotlib.pyplot as plt
from matplotlib.ticker import NullLocator
import os

# ---------------------------
# 1) Geração dos dados (2D)
# ---------------------------
def generate_data(n_per_class=1000, seed=42):
    rng = np.random.default_rng(seed)
    mean0 = np.array([1.5, 1.5])
    cov0  = np.array([[0.5, 0.0], [0.0, 0.5]])
    mean1 = np.array([5.0, 5.0])
    cov1  = np.array([[0.5, 0.0], [0.0, 0.5]])
    X0 = rng.multivariate_normal(mean0, cov0, size=n_per_class)
    X1 = rng.multivariate_normal(mean1, cov1, size=n_per_class)
    X  = np.vstack([X0, X1])
    y  = np.hstack([np.zeros(n_per_class, dtype=int),
                    np.ones(n_per_class,  dtype=int)])
    return X, y

# -----------------------------------------
# 2) Perceptron simples (treinamento)
# -----------------------------------------
def perceptron_train(X, y, lr=0.01, max_epochs=10, seed=42):
    """
    Perceptron para labels {0,1} (mapeados para {-1,+1}).
    Treina até convergir (nenhuma atualização na época) ou até max_epochs.
    """
    rng = np.random.default_rng(seed)
    y_signed = np.where(y == 1, 1, -1)

    n, d = X.shape
    w = np.zeros(d, dtype=float)
    b = 0.0
    acc_history = []

    for _ in range(max_epochs):
        idx = rng.permutation(n)
        errors = 0
        for i in idx:
            xi = X[i]; yi = y_signed[i]
            # Atualiza apenas se misclassificado (ou no limiar)
            if (np.dot(w, xi) + b) * yi <= 0.0:
                w += lr * yi * xi
                b += lr * yi
                errors += 1

        # Acurácia ao final da época
        preds = np.where(X @ w + b >= 0, 1, -1)
        acc = (preds == y_signed).mean()
        acc_history.append(acc)

        # Convergência: nenhuma atualização em um passe completo
        if errors == 0:
            break

    return w, b, np.array(acc_history), len(acc_history)

# -----------------------------------------
# 3) Avaliação
# -----------------------------------------
def evaluate(X, y, w, b):
    y_signed = np.where(y == 1, 1, -1)
    preds = np.where(X @ w + b >= 0, 1, -1)
    acc = (preds == y_signed).mean()
    mis_idx = np.where(preds != y_signed)[0]
    return acc, mis_idx

# -----------------------------------------
# 4) Visualizações
# -----------------------------------------
def plot_data_and_boundary(X, y, w, b, mis_idx, save_path=None):
    class0 = X[y == 0]; class1 = X[y == 1]
    plt.figure()
    plt.scatter(class0[:,0], class0[:,1], label="Class 0", alpha=0.6, marker="o")
    plt.scatter(class1[:,0], class1[:,1], label="Class 1", alpha=0.6, marker="^")

    # w1*x + w2*y + b = 0  ->  y = -(w1/w2)*x - b/w2
    if abs(w[1]) > 1e-12:
        xs = np.linspace(X[:,0].min()-0.5, X[:,0].max()+0.5, 200)
        ys = -(w[0]/w[1]) * xs - b / w[1]
        plt.plot(xs, ys, label="Decision boundary")
    elif abs(w[0]) > 1e-12:
        x_line = -b / w[0]
        plt.plot([x_line, x_line], [X[:,1].min()-0.5, X[:,1].max()+0.5], label="Decision boundary")

    if mis_idx.size > 0:
        plt.scatter(X[mis_idx,0], X[mis_idx,1], label="Misclassified", marker="x", s=60)

    plt.title("Dataset with Perceptron Decision Boundary")
    plt.xlabel("x1"); plt.ylabel("x2"); plt.legend(loc="best")
    plt.tight_layout()
    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()

def plot_accuracy(acc_history, save_path=None, y_floor=0.99, top_headroom=0.002):
    """
    Plota a acurácia com epochs inteiros exatamente 1..N (N = len(acc_history)).
    Remove ticks fracionários no eixo X e deixa folga acima de 1.0.
    """
    epochs = np.arange(1, len(acc_history) + 1)

    plt.figure()
    plt.plot(epochs, acc_history, marker="o", linewidth=2)
    plt.title("Training Accuracy per Epoch", pad=12)
    plt.xlabel("Epoch"); plt.ylabel("Accuracy")

    ax = plt.gca()
    ax.set_xticks(epochs)                  # apenas inteiros (ex.: 1 e 2)
    ax.set_xlim(epochs[0] - 0.2, epochs[-1] + 0.2)
    ax.xaxis.set_minor_locator(NullLocator())  # sem marcas fracionárias
    ax.grid(True, axis="y", linestyle="--", linewidth=0.5)
    ax.grid(False, axis="x")

    # Base do Y perto de 1.0, topo com folga acima de 1.0
    y_min = float(np.min(acc_history))
    lower = min(y_floor, y_min - 0.001) if y_min >= 0.95 else max(0.0, y_min - 0.02)
    upper = 1.0 + top_headroom
    plt.ylim(lower, upper)

    plt.tight_layout()
    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()

    Exercício 2: Dados Parcialmente Sobrepostos

    Geração dos Dados

    Parâmetros utilizados: - Classe 0: \(\mu_0 = [3.0, 3.0]\), \(\Sigma_0 = \begin{bmatrix} 1.5 & 0 \\ 0 & 1.5 \end{bmatrix}\) - Classe 1: \(\mu_1 = [4.0, 4.0]\), \(\Sigma_1 = \begin{bmatrix} 1.5 & 0 \\ 0 & 1.5 \end{bmatrix}\) - Amostras: 1000 por classe

    Código do Exercício 2

    import numpy as np
import matplotlib.pyplot as plt
import os


# ---------------------------
# 1) Geração dos dados (2D)
# ---------------------------
def generate_data_ex2(n_per_class=1000, seed=123):
    rng = np.random.default_rng(seed)

    # Class 0
    mean0 = np.array([3.0, 3.0])
    cov0 = np.array([[1.5, 0.0], [0.0, 1.5]])  # variância 1.5, sem covariância

    # Class 1
    mean1 = np.array([4.0, 4.0])
    cov1 = np.array([[1.5, 0.0], [0.0, 1.5]])  # variância 1.5, sem covariância

    X0 = rng.multivariate_normal(mean0, cov0, size=n_per_class)
    X1 = rng.multivariate_normal(mean1, cov1, size=n_per_class)

    X = np.vstack([X0, X1])
    y = np.hstack([np.zeros(n_per_class, dtype=int),
                   np.ones(n_per_class, dtype=int)])
    return X, y


# -----------------------------------------
# 2) Perceptron simples (treinamento)
# -----------------------------------------
def perceptron_train(X, y, lr=0.01, max_epochs=100, seed=0, random_init=True):
    """
    Implementação do Perceptron para labels {0,1}.
    Internamente mapeamos para {-1, +1}.
    Se random_init=True, começa com pesos aleatórios pequenos.
    """
    rng = np.random.default_rng(seed)
    y_signed = np.where(y == 1, 1, -1)

    n, d = X.shape
    if random_init:
        w = rng.normal(0.0, 1e-3, size=d)
        b = float(rng.normal(0.0, 1e-3))
    else:
        w = np.zeros(d, dtype=float)
        b = 0.0

    acc_history = []

    for epoch in range(max_epochs):
        idx = rng.permutation(n)  # embaralha a ordem
        errors = 0

        for i in idx:
            xi = X[i]
            yi = y_signed[i]

            activation = float(np.dot(w, xi) + b)
            pred = 1 if activation >= 0 else -1

            if pred != yi:
                # Regra do perceptron:
                # w <- w + lr * yi * xi
                # b <- b + lr * yi
                w = w + lr * yi * xi
                b = b + lr * yi
                errors += 1

        # Acurácia após a época
        preds = np.where(X @ w + b >= 0, 1, -1)
        acc = float((preds == y_signed).mean())
        acc_history.append(acc)

        # Em dados não separáveis, raramente zera erros; se zerar, para cedo
        if errors == 0:
            break

    return w, b, np.array(acc_history), (epoch + 1)


# -----------------------------------------
# 3) Avaliação
# -----------------------------------------
def evaluate(X, y, w, b):
    y_signed = np.where(y == 1, 1, -1)
    preds = np.where(X @ w + b >= 0, 1, -1)
    acc = float((preds == y_signed).mean())
    mis_idx = np.where(preds != y_signed)[0]
    return acc, mis_idx


# -----------------------------------------
# 4) Visualizações
# -----------------------------------------
def plot_data_and_boundary(X, y, w, b, mis_idx, save_path=None):
    """
    Plota os pontos por classe e a fronteira de decisão w·x + b = 0.
    Amostras mal classificadas são destacadas com marcador 'x'.
    """
    class0 = X[y == 0]
    class1 = X[y == 1]

    plt.figure()
    plt.scatter(class0[:, 0], class0[:, 1], label="Class 0", alpha=0.6, marker="o")
    plt.scatter(class1[:, 0], class1[:, 1], label="Class 1", alpha=0.6, marker="^")

    # Fronteira de decisão:
    # w1*x + w2*y + b = 0  ->  y = -(w1/w2) * x - b/w2  (se w2 != 0)
    x_min, x_max = X[:, 0].min() - 0.5, X[:, 0].max() + 0.5
    if abs(w[1]) > 1e-12:
        xs = np.linspace(x_min, x_max, 200)
        ys = -(w[0] / w[1]) * xs - b / w[1]
        plt.plot(xs, ys, label="Decision boundary")
    elif abs(w[0]) > 1e-12:
        # Fronteira vertical: x = -b / w0
        x_line = -b / w[0]
        plt.plot([x_line, x_line], [X[:, 1].min() - 0.5, X[:, 1].max() + 0.5], label="Decision boundary")

    # Destacar mal classificadas
    if mis_idx.size > 0:
        plt.scatter(X[mis_idx, 0], X[mis_idx, 1], label="Misclassified", marker="x", s=60)

    plt.title("Exercise 2: Data & Perceptron Boundary")
    plt.xlabel("x1")
    plt.ylabel("x2")
    plt.legend(loc="best")
    plt.tight_layout()

    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()


def plot_accuracy(acc_history, title_suffix="(single run)", save_path=None):
    plt.figure()
    plt.plot(np.arange(1, len(acc_history) + 1), acc_history, marker="o")
    plt.title(f"Training Accuracy per Epoch {title_suffix}")
    plt.xlabel("Epoch")
    plt.ylabel("Accuracy")
    plt.grid(True, linestyle="--", linewidth=0.5)
    plt.tight_layout()

    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()


def plot_mean_accuracy_multiple_runs(all_acc_histories, save_path=None):
    """
    Plota a acurácia média e desvio-padrão ao longo das épocas,
    considerando múltiplas execuções.
    """
    max_epochs = max(len(hist) for hist in all_acc_histories)

    # Estender históricos mais curtos com último valor
    extended_histories = []
    for hist in all_acc_histories:
        extended = np.copy(hist)
        if len(extended) < max_epochs:
            last_val = extended[-1]
            extended = np.concatenate([extended, np.full(max_epochs - len(extended), last_val)])
        extended_histories.append(extended)

    acc_matrix = np.array(extended_histories)
    mean_acc = np.mean(acc_matrix, axis=0)
    std_acc = np.std(acc_matrix, axis=0)

    epochs = np.arange(1, max_epochs + 1)

    plt.figure()
    plt.plot(epochs, mean_acc, marker="o", label="Mean Accuracy")
    plt.fill_between(epochs, mean_acc - std_acc, mean_acc + std_acc, alpha=0.3, label="±1 Std Dev")
    plt.title("Mean Training Accuracy Across Multiple Runs")
    plt.xlabel("Epoch")
    plt.ylabel("Accuracy")
    plt.grid(True, linestyle="--", linewidth=0.5)
    plt.legend()
    plt.tight_layout()

    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()


# -----------------------------------------
# 5) Execução com múltiplas tentativas
# -----------------------------------------
if __name__ == "__main__":
    n_runs = 5
    X, y = generate_data_ex2(n_per_class=1000, seed=123)

    print(f"Runs: {n_runs}")

    # Múltiplas execuções
    results = []
    all_acc_histories = []

    for run in range(n_runs):
        # Seed diferente para cada run (inicialização aleatória)
        w, b, acc_history, epochs_run = perceptron_train(
            X, y, lr=0.01, max_epochs=100, seed=run*10, random_init=True
        )

        final_acc, mis_idx = evaluate(X, y, w, b)
        best_epoch_acc = float(np.max(acc_history))

        results.append({
            'run': run + 1,
            'final_acc': final_acc,
            'best_epoch_acc': best_epoch_acc,
            'epochs_run': epochs_run,
            'w': w,
            'b': b,
            'mis_idx': mis_idx,
            'acc_history': acc_history
        })

        all_acc_histories.append(acc_history)

        print(f"Run {run + 1}: epochs={epochs_run}, final_acc={final_acc:.4f}, best_epoch_acc={best_epoch_acc:.4f}")

    # Encontrar o melhor run (maior acurácia final)
    best_run = max(results, key=lambda x: x['final_acc'])
    print(f"\nBest run: {best_run['run']} with final_acc={best_run['final_acc']:.4f}")

    # Estatísticas finais
    final_accs = [r['final_acc'] for r in results]
    mean_final_acc = np.mean(final_accs)
    std_final_acc = np.std(final_accs)
    print(f"Final accuracy across runs: mean={mean_final_acc:.4f}, std={std_final_acc:.4f}")

    # Salvar gráficos do melhor run
    script_dir = os.path.dirname(os.path.abspath(__file__))
    out_dir = os.path.join(script_dir, "graficos_ex2")
    os.makedirs(out_dir, exist_ok=True)

    plot_data_and_boundary(X, y, best_run['w'], best_run['b'], best_run['mis_idx'],
                           save_path=os.path.join(out_dir, "data_boundary_best_run.png"))

    plot_accuracy(best_run['acc_history'], title_suffix=f"(best run: {best_run['run']})",
                  save_path=os.path.join(out_dir, "accuracy_best_run.png"))

    plot_mean_accuracy_multiple_runs(all_acc_histories,
                                     save_path=os.path.join(out_dir, "mean_accuracy_all_runs.png"))

    Análise Comparativa

    Impacto da Separabilidade Linear

    Aspecto Exercício 1 Exercício 2
    Separabilidade Linearmente separável Parcialmente sobreposto
    Convergência 2 épocas Não converge (100 épocas)
    Acurácia 100% ~68-72%
    Variabilidade Determinística Alta variabilidade

    Limitações do Perceptron

    O Exercício 2 evidencia as limitações fundamentais do perceptron:

    1. Teorema de Convergência: Apenas garante convergência para dados linearmente separáveis
    2. Dados sobrepostos: O algoritmo continua tentando separar classes não separáveis
    3. Ausência de regularização: Não há mecanismo para prevenir overfitting ou oscilação

    Fatores Geométricos

    Exercício 1: - Razão separação/dispersão: \(4.95/\sqrt{0.5} ≈ 7.0\) (alta separabilidade) - Sobreposição: Mínima (~0%)

    Exercício 2: - Razão separação/dispersão: \(1.41/\sqrt{1.5} ≈ 1.15\) (baixa separabilidade) - Sobreposição: Significativa (~30-40%)

    Conclusões

    Exercício 1

    • A alta separabilidade linear resulta em convergência rápida e acurácia perfeita
    • O perceptron encontra uma fronteira ótima que separa completamente as classes
    • A distância entre médias muito maior que a variância garante separação clara

    Exercício 2

    • A sobreposição parcial impede a convergência do algoritmo
    • Múltiplas execuções são necessárias para avaliar a performance média
    • A melhor acurácia (~72%) representa o limite teórico para separação linear destes dados

    Implicações Práticas

    1. Dados linearmente separáveis: O perceptron é uma escolha excelente - simples, rápido e ótimo
    2. Dados com sobreposição: Algoritmos mais sofisticados (SVM, redes neurais multicamadas) são necessários
    3. Avaliação: Múltiplas execuções são fundamentais para dados não separáveis devido à variabilidade

    Trabalhos Futuros

    Para melhorar a performance em dados não linearmente separáveis, podem ser exploradas: - Redes neurais multicamadas (MLPs) - Kernelização (SVM com kernels não-lineares) - Transformações não-lineares do espaço de características - Algoritmos ensemble
